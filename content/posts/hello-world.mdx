# Hello World

Welcome to my blog! This is built with **Next.js** and **MDX**, which means I can write posts in Markdown and include React components.

## Why MDX?

MDX is great because:

- Write in familiar Markdown syntax
- Embed React components when needed
- Syntax highlighting for code blocks
- Easy to version control

## Code Example

Here's a simple React component:

```jsx
function Greeting({ name }) {
    return <h1>Hello, {name}!</h1>
}
```
